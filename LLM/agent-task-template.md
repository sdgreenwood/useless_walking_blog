# Agent task template

## Role

Name one independent responsibility and whether implementation is authorized.

## Objective

State one concrete outcome.

## Expected base

Require the agent to verify repository state and current handoff.

## Relevant evidence

Link only the current contracts, code, and fixtures that affect the task.

## In scope

List bounded deliverables.

## Explicitly out of scope

Name tempting adjacent work and authority that remains with another role.

## Acceptance evidence

Require observable behavior and exact checks, not a narrative claim.

## Required handoff

Implementation is handed off through cohesive changed files, updated canonical docs, checks, and Git status. Research/review work should name one bounded repository-native report.

## Stop condition

State exactly where the agent stops instead of beginning another subsystem.
